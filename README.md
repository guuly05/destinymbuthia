# Destiny Mbuthia — Photography Portfolio

A modern, fluid, image-first portfolio website for **Destiny Mbuthia** — a 21-year-old freelance photographer, stylist, and journalism student at the University of Arkansas, originally from Uganda.

Specializing in **35mm Film (analog)** and **Digital Photography** with an emphasis on intentional lighting, creative direction, and authentic storytelling.

---

## 🌟 Key Features & Mediums

- **Dual Medium Curation**: Showcase and filter across 35mm analog film rolls (Kodak Portra, Fujifilm, Ilford) and digital editorial sessions.
- **Camera Viewfinder Aesthetics**: Camera reticle HUD corners, exposure meter accents (`-2 .. 0 .. +2`), and shutter/aperture spec metadata (`ISO 400 • f/1.8`).
- **35mm Film Reel Section**: Interactive horizontal 35mm film reel with authentic sprocket hole borders (`[ 01 A ]`, `[ 02 A ]`).
- **Color Grading Craft Slider**: Interactive split-screen slider comparing raw camera frames against final color-graded edits.
- **Appointment Request System**: Direct message inquiry form pre-filling session choices without auto-booking barriers.
- **Instagram Feed Showcase**: `@des.narratives` feed integration with photo overlays and direct social links.

---

## 📂 Site Structure & Clean SEO Routes

- `/` (`index.html`) — Home & Viewfinder Hero Showcase
- `/work` (`work.html`) — Selected Portfolio & Medium Filters (*Fashion*, *Portraits*, *Landscape*, *Photoshoots*, *Graduates*)
- `/about` (`about.html`) — Bio, Journalism background, Ugandan heritage & Editing craft
- `/investment` (`investment.html`) — Package rates for Digital, Film, and Hybrid sessions (\$30 – \$220)
- `/contact` (`contact.html`) — Appointment Request & Direct Message form

## 🚀 Running Locally

To run the local clean URL dev server:

```bash
# Start the clean URL server on port 8080
python server.py
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## ☁️ Deployment

This project includes pre-configured clean URL rules for instant deployment:

- **Vercel**: Includes `vercel.json` (`"cleanUrls": true`)
- **Netlify**: Includes `_redirects` clean route rewriting
